# Концепция Android-приложения "SambaLite"

## 1. Обзор

**SambaLite** — легкий, современный и открытый клиент для Android для работы с SMB/CIFS ресурсами (Samba). Цель — предоставить минималистичный, надежный и безопасный инструмент, позволяющий пользователям получать доступ к SMB-ресурсам в локальной сети — без лишних функций, рекламы и ненужных опций.  
Приложение ориентировано на технически подкованных пользователей, которые ценят простоту, прозрачность, конфиденциальность и open source.

## 2. Цели проекта и философия

- **Минимализм:** Только необходимые функции, никаких лишних настроек и опций.
- **Удобство:** Чистый, аккуратный интерфейс, интуитивно понятный, с минималистичным дизайном.
- **Современность:** Использование актуальных библиотек и лучших практик Android-разработки (Java, Gradle, Dagger, Material Design).
- **Конфиденциальность:** Отсутствие телеметрии и слежки, безопасное хранение данных.
- **Поддерживаемость:** Чистый, хорошо документированный код, легко расширяемый и поддерживаемый.

## 3. Целевая аудитория

- Технически подкованные пользователи, желающие получить доступ к Samba-ресурсам дома или в небольшой сети.
- Системные администраторы и продвинутые пользователи, которым нужна легкая и независимая от облака альтернатива.
- Энтузиасты open source.

## 4. Набор функций (MVP)

### 4.1. Управление подключениями

- Ввод сервера SMB (имя хоста или IP) и ресурса/пути
- Имя пользователя, пароль, необязательный домен (рабочая группа)
- Управление несколькими подключениями с настраиваемыми псевдонимами
- Тест подключения (с понятным выводом ошибок)
- Автоматическое и безопасное хранение учетных данных (Android Keystore)

### 4.2. Файловый браузер

- Навигация по дереву ресурсов (папки, подпапки)
- Отображение: имя, тип (иконка), размер, дата изменения, если нужно — символ типа файла
- Обновление списка ("pull-to-refresh")
- Опции сортировки (по имени, дате, размеру)

### 4.3. Операции с файлами

- Скачать файлы (через Storage Access Framework)
- Загрузить файлы (выбор файлов через Storage Access Framework)
- Удаление файлов/папок (с подтверждением)
- Переименование файлов/папок
- Открытие файлов во внешних приложениях (ACTION_VIEW intent)
- Просмотр свойств файла (имя, размер, тип, путь, дата изменения)

### 4.4. Настройки

- Язык: системный (без внутреннего управления языками)
- Темная/светлая тема (по умолчанию системы)
- Опция удаления всех сохранённых подключений и учетных данных

### 4.5. Безопасность

- Нет телеметрии и сторонних сервисов
- Нет незашифрованного хранения чувствительных данных
- Минимальные разрешения (только сеть и доступ к выбранному пользователем хранилищу)
- Предупреждение о рисках при подключении к публичным/небезопасным сетям при первом запуске

## 5. Техническая архитектура

### 5.1. Язык и система сборки

- **Java 11+** (для современных возможностей языка, потоков, удобства поддержки)
- **Gradle** (последняя версия плагина для Android)

### 5.2. Архитектура

- **MVVM** (Model-View-ViewModel), ViewModel — на Java
- **Dagger 2** — для внедрения зависимостей
- **Паттерн Repository** для разделения UI, логики и сетевых операций
- **SMBJ** — библиотека клиента SMB (лицензия Apache 2.0, поддержка SMB2/3)

### 5.3. Основные компоненты

- **Activities/Fragments:** экран подключения, обзор подключений, файловый браузер
- **ViewModels:** управление подключениями, операции с файлами
- **Репозиторий:** абстракция SMB-операций (подключение, листинг, работа с файлами)
- **Утилиты:** вспомогательные функции, обработка ошибок, менеджмент хранения
- **Модули/компоненты Dagger:** поставка зависимостей

### 5.4. Хранение данных

- Учетные данные зашифрованы (Android Keystore + EncryptedSharedPreferences)
- Локальное хранение недавних подключений (только метаданные, без открытых паролей)
- Нет локальной базы файлов — листинг запрашивается с сервера по требованию

## 6. Пользовательский интерфейс (UI/UX)

- Material Design (современно, аккуратно)
- **Главный экран:** список сохраненных подключений, кнопка добавления нового
- **Диалог подключения:** сервер, ресурс, пользователь, пароль, домен (опционально), кнопка "Тест", опция сохранения
- **Файловый браузер:** навигация как в классическом просмотрщике, иконки по типам, контекстное меню для операций
- **Операции:** диалоги подтверждения для критичных действий, snackbar с результатами (успех/ошибка)
- **Обратная связь:** ошибки четко и понятно отображаются (сеть, аутентификация и пр.)
- **Настройки:** минимализм, возможность сброса данных

## 7. Безопасность и конфиденциальность

- Хранение паролей исключительно в зашифрованном виде (Keystore, без открытых файлов)
- Нет телеметрии и аналитики
- Все сетевые операции выполняются в фоне (AsyncTask/ExecutorService или Android architecture components)
- Очистка временных файлов после загрузки и скачивания
- Четкие предупреждения о рисках в небезопасных сетях (например, Wi-Fi)

## 8. Расширяемость (будущие возможности)

- Избранное (файлы/папки)
- Миниатюры/превью популярных типов файлов
- Пакетные операции (мультивыбор)
- Индикаторы прогресса загрузки и скачивания
- Поддержка дополнительных возможностей SMB (гостевой доступ, анонимный просмотр)
- Оптимизация интерфейса для планшетов

## 10. Примеры пользовательских сценариев для реализации

- **Как пользователь**, я хочу создать новое SMB-подключение и безопасно сохранить мои учетные данные, чтобы быстро получать доступ к сетевым ресурсам.
- **Как пользователь**, я хочу легко перемещаться по ресурсам в понятном файловом браузере для быстрого поиска нужных файлов.
- **Как пользователь**, я хочу скачивать отдельные файлы, сохранять их на устройстве и открывать в сторонних приложениях.
- **Как пользователь**, я хочу загружать файлы на ресурс для удобного обмена между ПК и смартфоном.
- **Как пользователь**, я не хочу беспокоиться о защите моих данных — SambaLite не хранит их в открытом виде и не собирает статистику.

## 12. Риски и вызовы

- **Интеграция SMBJ:** обеспечить стабильную и эффективную работу SMB2/3 на Android.
- **Storage Access Framework:** корректно интегрировать для совместимости с последними версиями Android.
- **Тайм-ауты сети/обработка ошибок:** дать пользователю понятные сообщения об ошибках и возможность повторной попытки.
- **Безопасность:** надежная реализация Keystore и шифрования.

# Заключение / Итог

**SambaLite** станет тем самым открытым Samba-клиентом для Android, о котором многие мечтали долгие годы:  
Современным, легким, надежным, без излишеств, но со всем необходимым для эффективного доступа к SMB-ресурсам.  
Благодаря Java, Gradle и Dagger код будет легким для понимания, модульным и максимально готовым к дальнейшей автоматизации и развитию с помощью ИИ.
