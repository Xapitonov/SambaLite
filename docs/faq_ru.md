# SambaLite FAQ

**Часто задаваемые вопросы и решения по подключению к Samba с SambaLite**

## 1. **Я не могу подключиться к своему Samba-серверу. Что делать?**

- Тщательно проверьте IP-адрес и имя ресурса.
- Убедитесь, что сервер находится в той же сети, что и ваше устройство.
- Проверьте подключение с помощью другого Samba-клиента (например, `smbclient` или VLC), чтобы исключить проблемы с сервером.

## 2. **Ошибка: "NT_STATUS_LOGON_FAILURE" или "Ошибка аутентификации"**

- Проверьте имя пользователя и пароль.
- Обратите внимание на регистр символов (заглавные/строчные).
- Если хотите подключиться без учетных данных, ресурс должен быть настроен с параметром **guest ok = yes**.
- Убедитесь, что пользователь существует на Samba-сервере и у него установлен пароль Samba (`sudo smbpasswd <username>`).

## 3. **Я не могу создавать папки или загружать файлы**

- Проверьте, не установлен ли для ресурса параметр **read only = yes**. Запись возможна только при **read only = no**.
- Убедитесь, что у общей папки правильные права на запись (например, `chmod 777` для тестирования).
- Пользователь, под которым вы входите, должен иметь права на запись на сервере.

## 4. **Гостевой доступ (анонимный вход) не работает**

- Ресурс должен иметь параметр **guest ok = yes**.
- В секции `[global]` добавьте **map to guest = Bad User**.
- Убедитесь, что существует гостевая учетная запись (по умолчанию это `nobody`).
- Папка должна быть доступна для чтения гостевой учетной записи (`chmod 755` и `chown nobody:nogroup <folder>`).

## 5. **Ошибка: "NT_STATUS_NO_SUCH_USER" или гостевой доступ запрещён**

- Проверьте, что пользователь создан правильно (`sudo smbpasswd -a <username>`).
- Для гостевого доступа смотрите предыдущий пункт.

## 6. **Я не вижу ресурс в списке доступных ресурсов**

- Убедитесь, что для общего ресурса установлен параметр **browseable = yes**.
- Проверьте, не блокирует ли доступ брандмауэр (порт 445/TCP должен быть открыт).
- Не все клиенты автоматически показывают все ресурсы — в SambaLite может понадобиться ввести имя ресурса вручную.

## 7. **Как создать логи сервера для устранения неполадок?**

- Повысите уровень логирования в вашем smb.conf (`log level = 3` в секции `[global]`).
- Логи обычно находятся в каталоге `/var/log/samba/`.
- Типичные команды для просмотра логов: `cat /var/log/samba/log.smbd` или `cat /var/log/samba/log.<clientname>`.

## 8. **Как добавить нового пользователя?**

```bash
sudo useradd -M -s /sbin/nologin <username>
sudo smbpasswd -a <username>
```

## 9. **Мой ресурс виден в сети, но я не могу к нему получить доступ**

- Проверьте права доступа к ресурсу в smb.conf.
- Убедитесь, что пользователь разрешен для доступа (`valid users = <username>` в секции ресурса).
- Проверьте, чтобы права файловой системы Linux соответствовали пользователю.

## 10. **Как включить гостевой доступ для ресурса?**

```ini
[public]
   path = /srv/public
   browseable = yes
   guest ok = yes
   read only = yes
```

И в секции `[global]`:

```ini
map to guest = Bad User
guest account = nobody
```
