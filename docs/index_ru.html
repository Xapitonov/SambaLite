О SambaLite

SambaLite — это легкий, современный клиент с открытым исходным кодом для Android для доступа к общим ресурсам SMB/CIFS (Samba). Он предоставляет минималистичный, надежный и безопасный инструмент для доступа к ресурсам SMB в локальных сетях без ненужных функций, рекламы или раздутого кода.

Ключевые особенности

  • Подключение к ресурсам SMB/CIFS с именем пользователя/паролем и доменом
  • Просмотр файлов и папок
  • Скачивание и загрузка файлов
  • Удаление и переименование файлов
  • Поиск с использованием шаблонов
  • Современный интерфейс с поддержкой темной темы
  • Управление несколькими подключениями
  • Безопасное хранение учетных данных
