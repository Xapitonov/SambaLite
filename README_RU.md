# SambaLite

*Посвящается моей жене Еве, которая вдохновила этот проект своей потребностью в организации файлов.*

SambaLite — это легкий, современный и открытый клиент для Android для работы с ресурсами SMB/CIFS (Samba). Он предоставляет минималистичный, надежный и безопасный инструмент для доступа к SMB-ресурсам в локальных сетях без лишних функций, рекламы или «раздутого» кода.

## Возможности

| Возможность           | Статус | Описание                                      |
| ---------------------- | ------ | --------------------------------------------- |
| Подключение SMB/ресурса | ✅     | Подключение с использованием имени пользователя, пароля и домена |
| Просмотр файлов        | ✅     | Навигация по папкам и файлам                   |
| Загрузка/выгрузка      | ✅     | Передача файлов между устройством и ресурсом  |
| Удаление/переименование| ✅     | Основные операции с подтверждением              |
| Поиск с шаблонами     | ✅     | Поиск файлов с помощью * и ?                   |
| Современный интерфейс | ✅     | Material Design с поддержкой темной темы       |
| Несколько подключений | ✅     | Управление несколькими ресурсами с кастомными именами |
| Безопасность и конфиденциальность | ✅ | Шифрованное хранение учетных данных, без телеметрии |

## Цели проекта

- **Минимализм:** только необходимые функции, без лишних настроек  
- **Удобство:** чистый, интуитивный и минималистичный интерфейс  
- **Современность:** использование актуальных библиотек и лучших практик Android  
- **Конфиденциальность:** отсутствие телеметрии, трекинга и лишних разрешений  
- **Поддерживаемость:** чистый и документированный код для простого расширения

---

## Технические детали

- **Язык:** Java 11 и выше  
- **Архитектура:** MVVM с паттерном Repository  
- **Зависимости:**  
  - AndroidX и компоненты Material Design  
  - Dagger 2 для внедрения зависимостей  
  - SMBJ для работы с SMB  
  - EncryptedSharedPreferences для безопасного хранения данных

---

## Заметки по безопасности

- Учетные данные надежно хранятся с использованием Android Keystore  
- Нет незашифрованного хранения конфиденциальных данных  
- Минимальные разрешения (только сеть и доступ к выбранным пользователем хранилищам)  
- Будьте осторожны при использовании SMB в публичных или ненадежных сетях
